# Sin90 验收标准（用户视角，本轮 M3–M5）

> 判断依据：**Sin90 能按我的节律提醒我、帮我复盘，AI 只提建议不替我做主 —— 而且它是一个装上去的包，不是内核的一部分。**
> 技术拆解见 [`tasks.md`](tasks.md)。记录日期：2026-09-23。

## M3 节律会响，而且不会重复

| 子项 | 要求 |
|:---|:---|
| 能表达重复节律 | 「每周一三五 7 点运动」存得下、改得了、能暂停、能退役 |
| 真的会响 | 到点 Sin90 记下一次触发，`/today` 能看到今天该做的 Routine |
| 重启不重复 | daemon 重启、Sin90 重启，内核里这条节律仍然只有一条 |
| 暂停就不响 | 暂停后内核那条变为禁用；退役后内核那条消失 |
| 注意力配额可调 | Rhythm 能建能看；调整要经提议 + 我批准 |

## M4 复盘可信

| 子项 | 要求 |
|:---|:---|
| 有地方写 | 日/周/节律三种复盘，草稿可改，定稿不可改 |
| 数字可信 | 周复盘草稿里的小时数只来自事件回放，偷偷改表不影响它 |
| 能带走 | 定稿存成 Markdown 文件（单向导出） |
| 到点自动起草 | 复盘 Routine 到点自动生成本期草稿，不会重复生成 |

## M5 AI 只提建议

| 子项 | 要求 |
|:---|:---|
| 三个能力 | 分类 inbox、总结复盘、排期建议 —— 只有这三个 |
| 只走提议门 | AI 的每项改动都是一条待我批准的提议；AI 代码碰不到直写接口 |
| 默认本地 | 不开远端时只用本地模型；断网时分类照常可用 |
| 可追溯 | 每次 AI 调用都有记录（用了哪个引擎、是否降级、耗时） |

## 明确不在本轮

Life Packs（M6）、可视化（M7+）、多用户。
